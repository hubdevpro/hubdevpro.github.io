Auth0: making sure HubSpot knows who’s logged in

Auth0 handles login, so your app doesn’t have to store passwords or reinvent security. The part that’s easy to get wrong is keeping that identity in sync with HubSpot – that’s where I come in.

01 · What is it

Auth0, explained in plain English

Auth0 is an identity provider – it handles login, sign-up, password resets and single sign-on (SSO), so you’re not storing passwords yourself or rebuilding security from scratch. It’s reliable and well-audited. The gap most businesses hit isn’t Auth0 itself – it’s that "who is this person" needs to mean the same thing in your app, in Auth0, and in HubSpot. That’s the bridge I build.

03 · Under the hood

A token verification check, for context

VerifyAuth0Token.php
class VerifyAuth0Token
{
    public function handle(Request $req, Closure $next)
    {
        $token = $req->bearerToken();

        // verify signature against Auth0's public JWKS, not a shared secret
        $claims = JWT::verify($token, Auth0::jwks());

        if (!$claims || $claims->exp < time())
            abort(401);

        $req->setUserContext($claims->sub, $claims->roles);

        return $next($req);
    }
}

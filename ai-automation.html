01 · What is it

AI automation, explained in plain English

Not every lead comes in through a clean web form. A lot of real business – real estate enquiries, legal intake, support requests – arrives as unstructured text: an email forward, a portal notification, a PDF attachment. An LLM (I use the Claude API) reads that text the way a person would, pulls out the fields that actually matter – name, contact info, property, urgency, case type – and pushes a clean, structured record into HubSpot automatically. Low-confidence extractions get flagged for a human instead of silently trusted, so speed doesn’t come at the cost of accuracy.

03 · Under the hood

A lead-parsing call, for context

parse_lead.py
def parse_lead(raw_text: str) -> dict:
    # ask the model for structured fields, nothing more
    response = client.messages.create(
        model="claude-sonnet-5",
        max_tokens=512,
        tools=[LEAD_SCHEMA],
        messages=[{"role": "user", "content": raw_text}],
    )
    fields = extract_tool_call(response)

    # don't trust a low-confidence read blindly
    if fields["confidence"] < 0.7:
        flag_for_review(fields, raw_text)
        return fields

    hubspot.upsert_contact(fields)
    hubspot.advance_deal_stage(fields["deal_id"], "lead_qualified")
    return fields
